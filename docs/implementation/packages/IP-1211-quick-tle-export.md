## Package ID

## Title

Quick TLE Export for a Cell-Visible Satellite

## Objective

Let any cell copy a current-epoch two-line element set for any satellite it holds a `Track` on —
derived from that cell's own belief (`Track.state_estimate`), never ground truth — and let White
Cell do the same for any on-orbit satellite from ground truth, via a copyable text field plus a
copy-to-clipboard button (the project owner's own minimal-UI bar, `BL-0109`). The TLE is
generated by fitting SGP4 mean elements to the believed state at the current sim time, so it works
for both orbit kinds the engine propagates (TLE-sourced and Kepler+J2, including post-manoeuvre
objects), with a stated, tested accuracy bound.

## Design Decisions

1. **TLE generation method (`BL-0110`, FS-121 OQ4) — option (a): single-epoch SGP4 mean-element
   fit, applied uniformly to every orbit kind.**
   - Get the source ECI state `(r, v)` at `world.now` via `ModeratePropagator.rv()` (for a
     TLE-sourced orbit this is SGP4 of the stored lines; for Kepler+J2 it is `elements_to_rv`).
   - Compute target **equinoctial** elements `(a, h, k, p, q, λ)` *directly from `(r, v)`* —
     not via `rv_to_elements()`, which collapses the true anomaly to 0 for circular-equatorial
     states (planning prototype found the fit diverges at `i = 0` through that path). Non-singular
     elements make `e → 0` and `i → 0` safe.
   - Fixed-point iteration: start with mean ≈ target; each pass builds an SGP4 satellite record
     (`sgp4.api.Satrec.sgp4init`, `WGS72`, mode `'i'`, epoch = `world.now` expressed as days since
     1949-12-31 00:00 UT via the existing `geometry.micros_to_jd`), evaluates it at `tsince = 0`,
     converts its output to equinoctial elements the same way, and adds `(target − current)` (mean
     longitude difference wrapped to `(−π, π]`) to the guess. Stop when the SGP4 position at epoch
     is within 1 cm of the target, or after a **fixed maximum iteration count (50)**; deterministic
     either way.
   - **B\*:** carry the source TLE's B\* for a TLE-sourced orbit (preserves its SGP4 drag
     behaviour); `0` for Kepler+J2 orbits (the engine models no drag). `ndot`/`nddot` = 0.
   - **Formatting/checksum:** delegate to the `sgp4` library's own `sgp4.exporter.export_tle()`
     (present in the installed `sgp4` 2.27, verified at planning time) — no hand-rolled
     fixed-width writer.
   - **Accuracy bound (FS-121 AC6):** after the full text round trip (export → `Satrec.twoline2rv`
     → SGP4 at the TLE's own epoch), position must be within **1 km** of the source state. The
     planning prototype (scratch, not committed) measured ≤ ~51 m worst case across LEO (51.6°,
     SSO), MEO (GPS-like), GEO (incl. exactly equatorial-circular), Molniya HEO (e = 0.72) and
     near-retrograde (179.9°); the residual is TLE fixed-width field quantisation. The bound is a
     deliberate 20× margin. **Stated limitation** (surfaced in the API response and UI): the fit
     matches the believed state *at epoch*; propagated away from epoch, SGP4's model and the
     engine's Kepler+J2 model diverge — consistent with `ADR-0009`'s moderate-fidelity posture.
   - **Rejections (`ValueError` with a reason):** non-elliptic state (`e ≥ 1` or non-negative
     specific energy); perigee below the Earth's equatorial radius; SGP4 error code from
     `sgp4init`/evaluation; fit not within the 1 km bound after the iteration cap. Never emit a
     TLE that failed these checks.
   - *Why not (b):* re-epoching original TLE text gives no path for Kepler+J2 objects, which are
     most shipped vignettes' assets. *Why not (c):* narrows `FR-7440`'s "any satellite" scope
     (FS-121 Risks) — would need the project owner. Option (a) needs no new architecture
     interface (pure engine function; `Propagator` seam unchanged), so nothing routes to `03`.
2. **Catalog number / designator / name (`BL-0162`, FS-121 OQ8).** A TLE-sourced orbit carries its
   original catalog number, classification and international designator forward (read from its own
   `tle_line1` via `Satrec.twoline2rv`). A Kepler+J2 orbit (fictional, or a TLE object after a
   manoeuvre that dropped its lines) uses catalog number **`99999`**, classification `U`, and a
   blank international designator — the conventional "analyst/unknown object" placeholder, never
   a real object's identity. The object's simulator id is returned as a separate `name` field (not
   embedded in the TLE lines). *Note:* a manoeuvred TLE object's `OrbitState` is `source="kepler"`
   with no `tle_line1`, so it gets the placeholder — acceptable and documented.
3. **Route (`BL-0160`, FS-121 OQ6).** `GET /api/sessions/{sid}/tle/{cell}?object_id=<id>` →
   JSON `{cell, now, object_id, name, line1, line2, epoch_iso, source, fit_error_m, note}` where
   `source` ∈ `{"track", "truth"}`, `fit_error_m` is the measured round-trip position residual at
   epoch, and `note` is the fixed limitation text from Design Decision 1. `cell=white` reads
   ground truth via `get_godview()` — the identical wiring `IP-1300`'s `/ric_view/{cell}` uses
   (verified by `VR-1300`). A rejection is **404** with the reason as `detail` (same convention as
   `/ric_view` and `/telemetry`); a missing `object_id` is FastAPI's own 422. `cell=observer` is
   not special-cased (same as `/ric_view`); it is a read, so `_reject_observer` does not apply.
4. **UI placement (`BL-0161`, FS-121 OQ7).** A new **View ▾ → "TLE export"** menu item opening a
   small panel (sibling of the RIC frame view panel): an object `<select>` populated from the
   seat's candidates (cells: `SCENE.tracks[].object` only — Design Decision 5; White: every
   on-orbit asset in `ASSETS`), a read-only `<textarea>` holding exactly the two TLE lines, a
   **Copy** button (`navigator.clipboard.writeText` when available, else select-the-textarea +
   `document.execCommand("copy")` fallback for plain-HTTP LAN), the `fit_error_m`/`note`
   caption, and the server's `detail` on a 404. Fetch on open and on selection change only — no
   polling (a TLE is a snapshot the operator copies). Selection is not persisted.
5. **Own-asset scope (`BL-0159`, FS-121 OQ5 — `DEFERRED` to `04`).** Follow `FR-7440` literally: a
   cell-scoped request succeeds only when `world.track_for(cell, object_id)` exists **and** carries
   a `state_estimate`. A cell's own asset with no `Track` is rejected with a reason that says so
   ("no track held on …; own-asset export is not yet in scope"). Therefore `quick_tle()` must NOT
   reuse `_live_state()`'s own-asset-at-truth branch for cells — it calls `track_for()` directly;
   White Cell (`cell=None` path) uses `_live_state(world, None, id)` unchanged.

## Implementation Tasks

1. **Write the failing tests first** (Tests to Add), then implement until green — the project's
   mandatory test-first workflow.
2. `engine/tle_export.py`: implement Design Decision 1 exactly — equinoctial elements computed
   directly from `(r, v)` (eccentricity vector projected on the equinoctial frame; true longitude
   from `r`; mean longitude via the existing `orbit.true_to_mean`); inverse to classical elements
   for `sgp4init`; fixed-point loop with a 50-iteration cap and 1 cm early exit; `export_tle()`;
   parse the lines back with `Satrec.twoline2rv` and measure the residual at the TLE's own epoch;
   reject per Design Decision 1. Epoch: `micros_to_jd(t) - 2433281.5`. Units: `sgp4` works in km,
   km/s, radians, mean motion in rad/min — convert at the boundary.

   `tr = world.track_for(cell, object_id)` → reject if `None` or `tr.state_estimate is None`;

   `_PROP.rv(asset.orbit, world.now)`. Identity/B\* per Design Decision 2 (if the source

## Risks

- **Fit non-convergence on an exotic state** (e.g. a near-parabolic HEO, a cislunar `a`): bounded
  by the 50-iteration cap + 1 km acceptance check → rejected with a reason, never a bad TLE.
  Mitigation: the parametrised round-trip test covers every regime the shipped vignettes use.
- **Deep-space SGP4 (period ≥ 225 min)** uses SDP4 terms; the prototype converged for GEO/MEO/HEO
  within the bound. Any residual risk surfaces as a rejection, not silent error.
- **Off-epoch divergence** between SGP4 and Kepler+J2 is inherent and documented in the response
  `note` (Design Decision 1); an analyst using the TLE far from epoch sees SGP4's prediction, not
  the simulator's.
- **Clipboard API on plain-HTTP LAN** may be unavailable; the textarea selection fallback covers it.

## Rollback Considerations

Purely additive: one new engine module, one new session function + two pass-throughs, one new
read-only route, one new static panel. Rollback = revert the commit; no data migration, no
persisted state, no change to any existing function's behaviour, determinism unaffected (the
feature is read-only and never runs inside the event-log replay path).
